First release of Vera View: a fast, read-only viewer for diagrams saved in the Microsoft® Visio® file formats (.vsdx, .vsdm, .vstx, .vstm), for Windows, Linux and macOS.

## Downloads

| Platform | File | Notes |
| --- | --- | --- |
| Windows 10/11 (x64) | `VeraView-Setup-0.3.0.exe` | Installs for the current user, no admin needed. Adds Start menu and "Open with" entries. |
| Linux (x86_64) | `VeraView-0.3.0-x86_64.AppImage` | Runs on most distributions: `chmod +x` it, then run. |
| Debian / Ubuntu | `vera-view_0.3.0-1_amd64.deb` | `sudo apt install ./vera-view_0.3.0-1_amd64.deb` |
| macOS 11+ (Apple Silicon and Intel) | `VeraView-0.3.0.dmg` | Drag Vera View to Applications. |

The Microsoft Store version is distributed through the Store and isn't attached here.

## Features

- Opens large diagrams (tens of thousands of shapes) in seconds, with smooth pan and zoom
- Shapes, stencil (master) shapes, styles, connectors and arrowheads, groups, rotation
- Fill colours and transparency, line weights, colours and dash patterns
- Formatted text: sizes, bold, italic, underline, colour, alignment, rotation
- Embedded PNG, JPEG, BMP and GIF pictures
- Multiple pages and background pages
- Find text across every page, with highlighted matches
- Scroll bars, mouse wheel and keyboard scrolling; Ctrl + wheel or pinch to zoom
- Read-only and offline: never changes your files, collects no data

## Known limitations

- Older binary .vsd files aren't supported (save them as .vsdx in Visio first).
- EMF/WMF pictures show as a placeholder; gradients, shadows and theme effects are simplified.
- The builds aren't code-signed yet, so Windows SmartScreen ("More info" → "Run anyway") and
  macOS Gatekeeper (right-click the app → Open) warn the first time.
- The Linux and macOS builds are new and have had little real-world testing.
